## 4. 提示词、模板与解码参数

- **模板**：每个模型用各自**官方**的对话 / 工具调用模板（HF `tokenizer_config.json` 里的 `chat_template`，或 BFCL 内置 handler）。
  我们的模型用导出目录里的 `chat_template`（`zero/post/chat.py` 的 `CHAT_TEMPLATE`，与训练时逐字一致，`tests/test_chat.py` 保证）。
- **系统提示词**：各基准官方默认；没有官方默认的一律不加。
- **思考模式**：对手有思考 / 非思考两种模式时**两种都测**，比较时取较高分（GOAL.md 3.2 第 4 条）。我们的模型默认非思考。
- **解码参数**（全部模型相同）：TBD。候选：贪心（temperature = 0，BFCL 默认 0.001）；max_new_tokens TBD（思考模式另设上限 TBD）；
  需要采样的基准（如 pass@k）固定 temperature / top_p / 种子 / 样本数。
- **少样本数**：按各基准在 lm-eval 里的默认设置，冻结时逐项写明。

## 6. "超过"的判定标准

- 每个基准上：对同一组题的逐题得分做**配对 bootstrap**（`zero/eval/bootstrap.py`，重采样 10,000 次，百分位法 95% 置信区间），
  差值 = 我们 − 对手（对手取两种模式中的较高者）。
  - 置信区间下界 > 0 → **超过**；上界 < 0 → **落后**；跨过 0 → **持平**。
- **硬目标成立**的条件：TBD（候选：BFCL 总分对清单里每一个对手都是"超过"；中文工具调用基准对每一个对手不"落后"）。
  多重比较：TBD（候选：主结论只看预先指定的一个总分；各子类别只作描述性报告）。
- 官方公布的分数并列展示，但不作为比较依据。

## 7. 去污染方法

- **n-gram 重叠**：所有训练数据（预训练、中期训练、SFT、教师合成数据、偏好数据、RL 任务）与全部评测集做 13-gram 重叠检查
  （`zero/data/decontam.py`），命中的训练文档删除或整段屏蔽；统计命中率写进模型卡。
- **工具调用专项**：训练用的函数名、参数 schema 与 BFCL 等评测集比对，重合的函数整体剔除；记录剔除数量。
- **自建环境**：`zero/post/envs/tool_env.py` 的训练任务与其固定 dev 集按问题文本去重（天气、寒暄两类问题空间太小，无法去重，单列报告）。
