# 第 3 章自我检验：非线性与神经网络

用户调用了 `/ch03-neural-network`，说明他们刚学完第 3 章（`chapters/03-neural-network/`）。你的任务是帮他们检验自己是否真正理解了，而不是告诉他们答案。

**检验方式**：逐一提问下面的问题，等用户用自己的话回答后，再给出反馈——哪里说对了，哪里还有偏差，以及如何深化理解。不要一次性把所有问题都抛出去。

---

## 检验问题（按难度递进）

**第一关：线性叠加还是线性**

问用户：
> 一个网络有三层线性层 1→8→8→1，一共 97 个参数，中间没有激活函数。它能拟合 y = sin(2x) 吗？用一个式子说明为什么。

期望回答：不能。`(X·W1 + b1)·W2 + b2 = X·(W1·W2) + (b1·W2 + b2)`，线性层的复合还是线性层，三层也能一路合并成 `X·W + b`，图像是一条直线，MSE 不可能低于最好的直线（本章是 0.4341）。能提到"代码里逐层算和合并算只差 10⁻¹⁵"或"两层线性训练后卡在 0.4341"是加分项。

---

**第二关：一个 ReLU 单元长什么样**

问用户：
> 一个隐藏单元对输出的贡献是 `v · ReLU(w·x + b)`，取 w = 2、b = −1、v = −3。画出（或描述）这条线：折点在哪里？折点左边、右边分别是什么样子？

期望回答：折点在 x = −b/w = 0.5。x < 0.5 时 `w·x + b < 0`，ReLU 输出 0，这一段是水平的 0；x > 0.5 时输出 `−3·(2x − 1)`，是一条斜率为 −6 的向下的直线。如果用户把折点算成 b/w 或把方向弄反，让他们代入 x = 0 和 x = 1 验算。

---

**第三关：宽度和死单元**

问用户：
> 本章里宽度 2 的网络损失停在 0.3155，只比直线的 0.4341 好一点；宽度 8 在不同随机种子下从 0.0064 到 0.0628 都有。分别解释这两个现象。

期望回答：宽度 2 最多两个折点、三段直线，sin(2x) 在 [−3, 3] 上有四个弯，模型容量不够，再怎么训练都拼不出来。宽度 8 刚够用但没有冗余：初始折点的位置、有没有单元"死掉"（z 在所有数据上都 < 0，ReLU′ 恒为 0，参数再也不更新）、折点有没有挤在一起（本章种子 0 有 4 个折点挤在 2.2–3.0）都会影响结果；宽度 64 有大量冗余，所以稳定得多。

---

**第四关：迁移**

问用户：
> 把 ReLU 换成 SiLU（`z · σ(z)`），第 5 节"一个单元 = 一个折点、输出是折线"的说法还成立吗？手推梯度的代码里哪一行要改，改成什么？现代大模型为什么更常用 SiLU/GELU 而不是 ReLU？

期望回答：不再是严格的折线——SiLU 处处光滑，一个单元贡献的是一段"圆角的弯"，但"很多个弯加起来拼出曲线"的直觉不变。梯度代码里只有 `act_grad` 那一行要改：ReLU′(z) 换成 SiLU′(z) = σ(z) + z·σ(z)·(1 − σ(z))；其余链式法则完全不变。更常用的原因：平滑、z < 0 时梯度不严格为 0（缓解死 ReLU）；而且大模型的前馈层用的是 SwiGLU（门控 + SiLU），第 9 章会讲。不要求用户背出 SiLU 的导数，能说出"只改激活函数的导数那一行"即可。
