## 二、分镜与旁白

### S01 片头
- 画面：章节标题卡淡入："第 5 章 / 分类与概率 / From 0 to AGI"，下方副标题。
- 屏幕文字：第 5 章 · 分类与概率
- 旁白：前四章，我们的模型都只会输出一个数。可是很多问题的答案不是一个数，而是"哪一类"：这张图是猫还是狗？这封邮件是不是垃圾邮件？还有这门课最关心的那个问题：这句话的下一个字是什么？这一章，我们来教模型做选择题。

### S02 为什么不预测编号
- 画面：数轴上 0、1、2 分别标着猫、狗、鸟；一个预测点落在 1（猫和鸟的平均）上，标红问号。右边改为三个输出框，每类一个分数。
- 屏幕文字：不要预测编号；有几类，就输出几个分数
- 旁白：最偷懒的办法，是把猫、狗、鸟编号成零、一、二，然后用回归去预测这个数。问题是，编号带来了不存在的顺序。如果模型在猫和鸟之间拿不准，回归会输出它们的平均值一，而一恰好是狗。换个思路：有几类，模型就输出几个分数，每类一个。这些分数叫作 {logits|logits}，可以是任意实数。

### S03 softmax：把分数变成概率
- 画面：三根柱子表示 logits [2, 1, −1]（鸟为负），变形为 exp 的柱子，再变形为概率柱子，柱顶数字随之变化；右侧 softmax 公式。
- 屏幕文字：softmax：p_k = exp(z_k) / Σ exp(z_j)
- 旁白：怎么把一组分数变成概率？要满足两个条件：每个数都是正的，加起来等于一。{softmax|soft max} 用最直接的办法做到：先取指数，一定是正的；再除以总和，一定加起来是一。比如猫、狗、鸟的分数是二、一、负一，取指数之后是七点三九、二点七二和零点三七，归一化以后，概率是零点七一、零点二六和零点零四。分数越高，概率越大，而且指数会放大差距。

### S04 数值稳定：先减最大值
- 画面：logits 放大成 [1000, 500, −500]，朴素算法得到 [nan, 0, 0]（红色）；每个数减去 1000 → [0, −500, −1500]，得到 [1, 0, 0]（绿色）。
- 屏幕文字：softmax(z) = softmax(z − max z)
- 旁白：指数长得太快了。在三十二位浮点数里，e 的八十九次方就已经溢出成无穷大。如果分数是一千、五百和负五百，照定义直接算，得到的是 {nan|N A N}。办法是利用 {softmax|soft max} 的一个性质：给所有分数减去同一个数，结果不变。那就先减去最大值，最大的一项变成 e 的零次方，等于一，永远不会溢出。所有深度学习框架里的 {softmax|soft max}，都是这么写的。

### S05 最大似然
- 画面：一串样本，每个写着"正确答案的概率 0.9"，相乘的结果从 0.35 缩小到 10⁻⁴⁶、10⁻³²³；然后 log 把连乘变成求和，得到负对数似然公式。
- 屏幕文字：最大似然 → 取 log → 负对数似然 L = −1/N Σ log p_{y_i}
- 旁白：有了概率，训练目标就很自然了：让模型给正确答案的概率尽量大。整个数据集猜中所有答案的概率，是每个样本概率的乘积，这叫似然，让它最大，叫最大似然估计。但是连乘会下溢：就算每个样本都给正确答案零点九的概率，一千个样本乘起来是十的负四十六次方，一万个就贴近浮点数的极限了。所以取对数，乘积变成求和。再加个负号、取平均，就得到负对数似然，越小越好。

### S06 交叉熵：−log p
- 画面：左边画出 −ln p 曲线（p 从 0 到 1），标出猫 0.705 → 0.349、狗 0.259 → 1.349、鸟 0.035 → 3.349 三个点，以及 ln 3 的虚线；右边写 onehot 下交叉熵只剩一项。
- 屏幕文字：交叉熵 H(q, p) = −Σ q_k log p_k = −log p_y
- 旁白：负对数似然还有一个更常用的名字：交叉熵。真实答案是一个 {onehot|one hot} 分布，正确的那一类是一，其余是零，所以交叉熵只剩下一项：负的 log，正确答案的概率。看这条曲线：如果正确答案是猫，概率零点七一，损失只有零点三五；如果正确答案是鸟，概率只有零点零四，损失是三点三五。概率越接近零，损失越大，没有上限。还有一个有用的数：三类均匀乱猜的损失，是 {ln 3|自然对数 三}，约等于一点一。一个还没学的模型，初始损失应该就在这附近。

### S07 梯度：p − onehot
- 画面：推导 L = −z_y + log Σ exp(z_j) → ∂L/∂z_k = p_k − [k = y]；下方三组柱子：p（绿）减去 onehot（黄框）得到梯度（红，猫为负）；数值梯度对拍的数字。
- 屏幕文字：∂L/∂z = p − onehot
- 旁白：接下来是这一章最漂亮的结论。把 {softmax|soft max} 代进交叉熵，对每个分数求导，指数和对数的复杂性全部抵消，梯度就是 {p − onehot|p 减 one hot}：模型的预测减去正确答案。正确那一类的分数被往上推，推的力度是还差多少；每个错误类别被往下压，力度正是模型错给它的概率。我们用中心差分做了梯度检验，两者的差只有十的负十二次方。

### S08 为什么不用 MSE：梯度对比
- 画面：横轴是"错误类别的 logit s"（0 到 10），纵轴是梯度大小（对数刻度）；红线交叉熵平稳在 1.41，灰线 MSE 从 0.54 一路跌到 3.4×10⁻⁴。
- 屏幕文字：自信地错了：CE 梯度 ≈ 1.41，MSE 梯度 → 0
- 旁白：那能不能继续用老朋友均方误差，让概率去逼近 {onehot|one hot}？问题出在模型自信地错了的时候。我们让真实答案是第零类，却把错误类别的分数一点点抬高。交叉熵的梯度越来越大，最后稳定在一点四一；{MSE|M S E} 的梯度却越来越小，分数差到十的时候，只剩万分之三点四，比交叉熵小四千多倍。原因是 {MSE|M S E} 的梯度要穿过 {softmax|soft max} 的导数，里面乘着概率，概率接近零，梯度也跟着消失。交叉熵里的对数，恰好把指数抵消掉了。

### S09 为什么不用 MSE：训练对比
- 画面：两条准确率曲线（横轴步数 0–3000）：交叉熵（红）迅速升到 97%；MSE（灰）在 65% 附近平躺到 800 步才爬起来；标出"500 步时 p(正确) < 1% 的样本：CE 0 个，MSE 103 个"。
- 屏幕文字：一开始就自信地乱猜：MSE 卡住七八百步
- 旁白：这不只是纸面上的数字。我们故意把输出层初始化得很大，让模型一开始就自信地乱猜，再用同一个网络、同样的学习率，分别用交叉熵和 {MSE|M S E} 训练。交叉熵一百步就到了百分之八十六，五百步百分之九十七。{MSE|M S E} 却在百分之六十五附近躺了七八百步。第五百步时，有一百零三个样本给正确答案的概率还不到百分之一，三分之一的数据自信地错着，却推不动参数。所以分类的默认损失，是交叉熵。

### S10 螺旋数据：直线切不开
- 画面：左边坐标系里三色螺旋点（每类 100 个）淡入；叠上线性 softmax 分类器的决策区域（三块扇形），标注准确率 54.0%。
- 屏幕文字：三类螺旋，300 个点；线性分类器：54.0%
- 旁白：现在把零件装起来，训练一个真正的分类器。数据是三条交错的螺旋，每类一百个点，在代码里生成。先试试没有隐藏层的线性分类器：它的每条边界都是直线，只能把平面切成三块扇形，准确率只有百分之五十四。分类问题照样需要第三章的非线性。

### S11 MLP 训练：决策区域长成螺旋
- 画面：换成两层 MLP（2→64→3）的决策区域，从第 0 步的一片颜色，依次变到第 20、50、100、200、500、3000 步，三种颜色卷成三条螺旋；右侧步数、交叉熵、准确率计数器同步变化。
- 屏幕文字：MLP 2→64→3 + softmax + 交叉熵
- 旁白：换成两层的 {MLP|M L P}：两个输入，六十四个隐藏单元，三个输出，后面接 {softmax|soft max} 和交叉熵。反向传播和上一章一样，只是起点换成了 {p − onehot|p 减 one hot}。画面里每一个位置，都涂成模型在这里预测的类别颜色。一开始，损失是一点零九，正好约等于 {ln 3|自然对数 三}，模型在均匀地猜。随着训练，三种颜色慢慢卷起来，一百步准确率百分之九十三，五百步百分之九十九。三千步后，交叉熵降到零点零三。另造一份测试数据，准确率也是百分之九十九。

### S12 温度
- 画面：猫狗鸟的概率柱子随温度 T 从 1 → 0.5 → 2 → 10 变化；T 的数值显示在上方。
- 屏幕文字：softmax(z / T)：T 小更尖，T 大更平
- 旁白：{softmax|soft max} 还有一个旋钮，叫温度：先把分数除以 T，再做 {softmax|soft max}。温度调到零点五，差距被放大，猫的概率升到零点八八，分布更尖。温度调到十，差距被压小，三类都在零点三左右，接近均匀。训练时温度一般就是一。它真正登场是在第十章：语言模型生成文字时，温度决定模型是总挑最可能的字，还是更大胆地尝试。

### S13 语言模型 = 在词表上分类
- 画面：一行字"猜 下 一 个 字"，箭头指向"下一个字的概率"柱状图（「分」之后：数 0.67、类 0.33）；右侧表格：损失 4.17 nats（= ln 65，困惑度 65）→ 0.46 nats（0.67 bits，困惑度 1.59）；底部 GPT-2：ln 50257 = 10.82。
- 屏幕文字：语言模型 = 在词表上做分类；损失 = 交叉熵
- 旁白：现在是这一章最重要的一点：语言模型，就是一个在词表上做分类的分类器。看前面的字，猜下一个字，类别数就是词表的大小。我们用一小段中文，六十五个不同的字，训练一个只看上一个字的模型，代码和螺旋分类器用的是同一个交叉熵、同一个梯度。初始损失四点一七，正好是 {ln 65|自然对数 六十五}；训练后降到零点四六。它学到，「分」后面是「数」的概率零点六七，是「类」的概率零点三三，这正是语料里的频率。损失的单位有三种写法：自然对数叫 {nats|nats}，换成以二为底叫 {bits|bits}，再取指数叫困惑度。困惑度从六十五降到一点五九，意思是从在六十五个字里瞎猜，变成只在一两个字之间犹豫。换成 {GPT-2|G P T 2} 五万多个 token 的词表，初始损失就该是十点八二。

### S14 从极简到生产级
- 画面：左边手写的 log_softmax + cross_entropy 几行 NumPy，右边 PyTorch 的 `F.cross_entropy(logits, y)`；对拍数字 3.1764553511 两边一致；再显示 logits 形状 (B, T, V) → (B·T, V)。
- 屏幕文字：F.cross_entropy 吃 logits，内部融合 log-softmax
- 旁白：{PyTorch|Py torch} 里，这一切是一行：{F.cross_entropy|F 点 cross entropy}。注意它吃的是 {logits|logits}，不是概率，内部把 log {softmax|soft max} 和负对数似然合在一起算，数值稳定。分数是一千、五百、负五百时，朴素写法得到无穷大，它算出一千五。我们把它和手写版对拍，结果逐位一致。在语言模型里，{logits|logits} 的形状是批次、长度、词表，拉平以后就是同一个分类损失。{nanoGPT|nano G P T} 和 {minimind|mini mind} 的模型代码，最后都是这一行。

### S15 小结与下一章
- 画面：一条流水线：logits → softmax → 概率 → −log p_y → 梯度 p − onehot；下方"语言模型 = 词表上的分类"；最后"下一章：让训练稳定"。
- 屏幕文字：logits → softmax → 交叉熵 → p − onehot
- 旁白：回顾一下：模型给每一类打一个分数；{softmax|soft max} 把分数变成概率；最大似然让正确答案的概率尽量大，也就是最小化交叉熵；梯度就是 {p − onehot|p 减 one hot}。分类不用均方误差，因为自信地错的时候，它没有梯度。而语言模型，就是在词表上做这件事。我们的螺旋分类器只有两层，训练得顺顺利利。可如果把网络加深到几十层，损失要么不动，要么爆炸。下一章，我们来学怎么让训练稳定。
