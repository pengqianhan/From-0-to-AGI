## 二、分镜与旁白

### S01 片头
- 画面：标题卡"第 23 章 / 线性注意力与混合架构"，副标题"把 KV cache 压成一个固定大小的矩阵"。
- 屏幕文字：第 23 章 · 线性注意力与混合架构
- 旁白：上一章我们用滑动窗口，让一部分注意力层只看最近的内容。这一章换一条路：能不能让注意力根本不用存越来越长的 KV cache，而是只维护一个固定大小的记忆？答案是线性注意力，以及今天几乎所有新模型都在用的混合架构。

### S02 问题：KV cache 越长越大
- 画面：左边一行 token 不断增加，下方 K、V 两排小方块跟着变长；右边一个 8×8 的方阵保持不动。底部数字：T=1024 → 256 KB，T=262144 → 65536 KB；状态恒为 8 KB。
- 屏幕文字：softmax 注意力：KV cache ∝ T　　线性注意力：状态大小固定
- 旁白：回忆一下 softmax 注意力。生成第 t 个词，要拿当前的 query，和前面全部 t 个 key 算分数，再加权全部 t 个 value。所以前面的 K 和 V 一个都不能丢，KV cache 随上下文线性增长。单层单头、六十四维的情况下，一千个 token 是 256 KB，二十六万个 token 就是六十多 MB。而右边这个方阵，是我们今天要得到的东西：不管上下文多长，它的大小都不变。

### S03 去掉 softmax：矩阵乘法换个顺序
- 画面：上排 (Q Kᵀ) V：T×d 乘 d×T 得到一个大的 T×T 方块，再乘 T×d；下排 Q (Kᵀ V)：先得到一个小的 d×d 方块。两个方块大小对比。
- 屏幕文字：(Q Kᵀ) V = Q (Kᵀ V)　　T×T → d×d
- 旁白：关键的一步很简单：把 softmax 拿掉。没有 softmax，注意力就只是三个矩阵连乘。矩阵乘法满足结合律，先算 {QKᵀ|Q 乘 K 的转置}，会得到一个 T 乘 T 的大矩阵；先算 {KᵀV|K 的转置乘 V}，得到的只是一个 d 乘 d 的小矩阵，和序列长度无关。softmax 不行，是因为它要对一整行分数一起归一化，拆不开。

### S04 递推形式：注意力变成了 RNN
- 画面：状态方阵 S 居中；每来一个 token，一个外积 v kᵀ（橙色小方阵）加到 S 上；然后 q 进来，S q 读出输出。公式逐行出现。右下角：两种算法最大相对误差 4.7e-07。
- 屏幕文字：S_t = S_{t−1} + v_t k_tᵀ　　o_t = S_t q_t
- 旁白：再加上因果掩码，每个位置只累加它之前的项。于是可以边走边算：维护一个状态矩阵 S，每来一个 token，就把 v 和 k 的外积加进去，这是写入；再用 q 乘 S，这是读出。这就是一个循环神经网络，每一步的内存和计算都是常数。我们用代码验证了，这种递推写法和一次性算大矩阵的写法，结果只差浮点舍入误差。

### S05 推理快了多少
- 画面：两条柱状对比（对数刻度），上下文 1K / 8K / 64K / 256K：softmax 解码一步的毫秒数逐渐升高，线性注意力一条水平线。
- 屏幕文字：解码一步：softmax ∝ T，线性 = 常数
- 旁白：推理时的差别非常直观。在 CPU 上测解码一步，softmax 注意力随上下文变长越来越慢，到二十六万个 token 时要二十毫秒以上；线性注意力始终是零点零三毫秒左右。当然，这只是单个注意力头的小实验，真实模型里还有很多别的开销。

### S06 训练用分块形式
- 画面：一条长序列被切成几块；块内是一个小三角形（并行计算），块与块之间有一个箭头传递状态 S。旁边速度表：T=4096 时，逐 token 递推 188 ms，分块 21 ms，完全并行 1114 ms。
- 屏幕文字：块内并行 + 块间递推
- 旁白：推理可以一步一步来，训练却要一次处理整段序列。逐个 token 的循环没法并行；完全并行又要算 T 乘 T 的矩阵。折中办法是分块：块内用矩阵乘法并行算，块与块之间只传一个状态。三种算法数值完全一致。在四千个 token 上，分块比逐 token 递推快约九倍，比完全并行快五十多倍。

### S07 代价：固定大小的记忆会满
- 画面：一个 64×64 的状态；往里写 N 个键值对，再逐个读回。表格：N = 16、64、256 时的读回误差，线性注意力 0.47 → 1.00 → 1.97；softmax 注意力一列全是 0.000。
- 屏幕文字：状态大小固定 → 容量有限
- 旁白：天下没有免费的午餐。把整段历史压进一个固定大小的矩阵，记忆就会满。我们往一个六十四乘六十四的状态里写入随机的键值对，再用 key 去读。写十六个时，读回的误差已经有零点四七；写到六十四个，误差和信号本身一样大；而 softmax 注意力把所有 K、V 原样存着，误差始终是零。这正是线性注意力最大的弱点：精确回忆。

### S08 衰减门：学会遗忘
- 画面：一个写入的信号随时间衰减的曲线，三条：α=1 平的，α=0.99 缓慢下降，α=0.9 很快归零；标注 0.904 / 0.366 / 0.007。
- 屏幕文字：S_t = α_t S_{t−1} + v_t k_tᵀ
- 旁白：第一个改进是加一个衰减门 {α|alpha}：每一步先把旧状态乘上一个小于一的数，再写入新内容。{α|alpha} 等于零点九九时，一个信息过了一百步还剩零点三七，过了五百步几乎为零。更重要的是，{α|alpha} 由当前输入算出来，模型可以自己决定什么时候该忘。RetNet、GLA、Mamba 2 这一族模型，骨架都是这个带衰减的递推。

### S09 delta 规则：覆盖而不是累加
- 画面：同一个 key 先写 v1=[1,0]，再写 v2=[0,1]。左边"线性注意力"读出 [1,1]，右边"delta 规则"读出 [0,1]。然后出现公式，高亮"v − S k"。
- 屏幕文字：S_t = S_{t−1}(I − β k kᵀ) + β v kᵀ
- 旁白：第二个改进更聪明，叫 delta 规则。线性注意力只会往里加：同一个 key 先写 v1、再写 v2，读出来是两者的和。delta 规则在写入之前，先用 k 读出旧答案，只把新值和旧答案的差写回去，{β|beta} 控制写多少。{β|beta} 等于一时，旧值被干净地覆盖，读出来正好是 v2。在容量实验里，delta 规则的误差也明显更低。

### S10 Gated DeltaNet
- 画面：两个公式合成一个：α_t 乘在 delta 规则前面。下方三个标签：衰减（忘掉过时的）、delta（覆盖旧值）、分块形式（可并行训练）；右下角"分块 == 递推：最大差 4.8e-07"。
- 屏幕文字：S_t = α_t S_{t−1}(I − β_t k_t k_tᵀ) + β_t v_t k_tᵀ
- 旁白：把两者乘在一起，就是 Gated DeltaNet：先按门衰减，再按 delta 规则覆盖。它同样有分块并行的训练形式，只是块内要多解一个三角方程组，我们也用代码验证了它和递推形式完全一致。千问 Qwen3-Next 和 Qwen3.5 的线性层，用的就是它。

### S11 混合：3:1 的层堆叠
- 画面：24 个小方块排成一列（Qwen3.5-0.8B 的真实 layer_types），每 4 个里 3 个紫色"Gated DeltaNet"、1 个蓝色"全注意力"。右边缓存对比：262144 个 token 时，KV 3072 MiB + 状态 18.6 MiB，对照"24 层全注意力"12288 MiB。
- 屏幕文字：Qwen3.5-0.8B：6 × (3 × Gated DeltaNet + 1 × 全注意力)
- 旁白：既然线性层记性有限，全注意力又太贵，工业界的答案是混合：大部分层用线性注意力，每隔几层放一层全注意力，专门负责精确回忆。这是 Qwen3.5 零点八 B 的真实配置，二十四层里每四层有三层 Gated DeltaNet、一层全注意力。KV cache 只跟着那六层全注意力走：二十六万个 token 时约三 GB，另外十八层的状态加起来不到二十 MB；如果二十四层全是注意力，要十二 GB。

### S12 小实验：混合能把回忆找回来
- 画面：右上角"极小规模实验"标注。左：四种结构的验证 loss 柱状图（AAAA / LLLL / GGGG / GGGA）。右：联想回忆准确率随键值对数量变化的折线，纯线性掉下去，混合与全注意力保持在高处。
- 屏幕文字：纯线性：回忆掉队　　混合：找回来了
- 旁白：最后是两个极小规模的实验。左边，四个同样大小的四层小语言模型，只换每层的注意力类型，各训练八百步：四种结构的验证 loss 相差不大，LMPLACEHOLDER。右边的实验更能说明问题，叫联想回忆：先给模型一串键值对，再反复问它某个键对应的值。纯注意力在二十四对时还有九成以上的准确率；朴素线性注意力从六成四一路掉到一成七；GGPLACEHOLDER；而只把两层中的一层换回全注意力，混合模型在二十四对时回到了七成九。规模很小，但方向和论文一致：精确回忆，要靠那几层全注意力。

### S13 谁在用
- 画面：一张表：千问 Qwen3-Next、Qwen3.5（Gated DeltaNet，3:1）；Kimi Linear（KDA 加 MLA，3:1）；蚂蚁 Ling 3.0（KDA 加 MLA，3:1）；英伟达 Nemotron-H 和 Nemotron 3（Mamba 2 加少量注意力）；IBM Granite 4.0（Mamba 2 比注意力 9:1）；Falcon-H1（同层并联）。最下面一行灰色：MiniMax-01 用过 7:1 的线性混合，M2 回到了全注意力。
- 屏幕文字：少量全注意力 + 大量线性层
- 旁白：这种"少量全注意力加大量线性层"的做法，已经被很多家独立采用：千问、Kimi、蚂蚁百灵用的是 DeltaNet 一族，英伟达、IBM 和 Falcon 用的是 Mamba 2 这类状态空间层，比例从三比一到九比一不等。但也有反例：MiniMax 的上一代用了七比一的线性混合，最新的 M2 却回到了全注意力，理由是线性注意力的基础设施、低精度推理和推测解码都还不成熟。所以，这是一个工程权衡，而不是免费的午餐。

### S14 从极简到生产级 + 下一章
- 画面：左边极简代码四行（S = S + outer(v, k)），右边 `zero/arch/linear_attention.py` 的结构：短卷积、L2 归一化、α、β、分块与递推两种算子、门控 RMSNorm；下面一行"与 HF Qwen3.5 GatedDeltaNet 权重对拍通过"。最后出现"下一章：混合专家 MoE"。
- 屏幕文字：生产级：与 Hugging Face 的 Qwen3.5 实现对拍
- 旁白：极简代码里，核心就是写入和读出两行。生产级的版本多了短卷积、q 和 k 的 L2 归一化、数据相关的 {α|alpha} 和 {β|beta}、门控归一化，以及分块和递推两套算子；我们把 Hugging Face 的 Qwen3.5 线性层权重搬进来，输出完全一致。真正训练时，还要换成 flash linear attention 的 GPU 内核。这一章让每个 token 的记忆变便宜了；下一章，我们让每个 token 的计算变便宜：混合专家，MoE。
