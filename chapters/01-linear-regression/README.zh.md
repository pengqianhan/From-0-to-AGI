这是整门课的第一章。课程最后讲到有几千亿参数的大语言模型。这里我们从一条直线开始：`y = ax + b`。训练大模型的结构和这一章的结构相同。唯一的区别是参数的数量：这里有 2 个，大模型有几十亿个。请学好这一章。后面的每一章都在问同一个问题："把这件事做大，会出现什么新问题？"

## 1. 直觉：什么是"训练"

你有一批数据点。每个点是一对 `(x, y)`。例如，`x` 是房子的面积，`y` 是房子的价格。画在图上，这些点大致在一条直线上，但不完全在线上。真实的数据总是有噪声。

你想要一个**模型**。给模型一个新的 `x`，模型预测出 `y`。最简单的模型是一条直线：

```
ŷ = a·x + b
```

这里的 `ŷ`（读作 "y hat"）是模型的**预测**。`a` 是斜率，`b` 是截距。`a` 和 `b` 是模型的**参数**（parameter）。这个模型的全部"知识"都在这两个数里。

问题是：`a` 和 `b` 取多少才对？

**训练**（training）让数据来决定参数。训练有四个步骤。这四个步骤出现在课程的每一章：

1. **模型**：写出预测的公式，`ŷ = a·x + b`。
2. **损失**（loss）：用一个数衡量预测有多差。
3. **梯度**（gradient）：算出参数往哪个方向移动，损失会变小。
4. **更新**（update）：让参数朝这个方向移动一小步。然后回到第 1 步，再做一次。

## 2. 损失：把"有多差"变成一个数

对第 `i` 个数据点，模型的预测是 `ŷ_i = a·x_i + b`，真实值是 `y_i`。差值 `ŷ_i − y_i` 叫作**残差**（residual）。把所有残差平方，再求平均。结果就是**均方误差**（mean squared error，MSE）：

```
L(a, b) = 1/N · Σ (a·x_i + b − y_i)²
```

平方有两个原因。第一，正误差和负误差不会互相抵消。第二，平方函数处处光滑，容易求导。下一节就要用到这个性质。

我们把损失写成 `L(a, b)`。**数据不变，所以损失是参数的函数。**换一对 `(a, b)`，就得到另一个损失值。画出所有 `(a, b)` 对应的损失，图形是一个碗。我们要找的是碗底。

## 3. 梯度：损失下降最快的方向

设想一个人站在山谷的坡上，四周有雾。他看不到谷底。他只能感受脚下的坡度，然后往最陡的下坡方向迈一步。

**梯度**就是这个坡度。它是损失对每个参数的偏导数组成的向量。梯度指向损失**上升**最快的方向。对均方误差，用链式法则可以直接算出梯度：

```
∂L/∂a = 2/N · Σ (ŷ_i − y_i) · x_i
∂L/∂b = 2/N · Σ (ŷ_i − y_i)
```

这两个公式的含义很直接。如果模型的预测整体偏高（大多数残差为正），`∂L/∂b` 就是正的，所以 `b` 要减小。残差和 `x` 的乘积告诉我们斜率 `a` 要增大还是减小。梯度不是一个抽象符号。它汇总了模型错在哪里、错了多少。

## 4. 更新：梯度下降

梯度指向上坡，所以我们朝相反的方向移动：

```
a ← a − η · ∂L/∂a
b ← b − η · ∂L/∂b
```

`η`（读作 "eta"）是**学习率**（learning rate）。它控制每一步的大小。这个过程就是**梯度下降**（gradient descent）：算出梯度，朝相反方向走一小步，再做一次。

## 5. 极简代码：60 行拟合一条直线

运行：

```bash
uv run python chapters/01-linear-regression/code/01_fit_line.py
```

核心是下面几行（完整代码见 [`code/01_fit_line.py`](code/01_fit_line.py)）：

```python
def gradients(a, b, x, y):
    err = (a * x + b) - y              # residual ŷ_i − y_i
    grad_a = 2 * np.mean(err * x)      # ∂L/∂a
    grad_b = 2 * np.mean(err)          # ∂L/∂b
    return grad_a, grad_b

for _ in range(steps):
    grad_a, grad_b = gradients(a, b, x, y)
    a = a - lr * grad_a                # a ← a − η · ∂L/∂a
    b = b - lr * grad_b                # b ← b − η · ∂L/∂b
```

我们造的数据，真实关系是 `y = 2x + 1`，再加上噪声。从一个很差的起点 `a = −1, b = 4` 出发，学习率取 0.05。输出如下：

| 步数 | a | b | 损失 |
|---:|---:|---:|---:|
| 0 | −1.000 | 4.000 | 44.23 |
| 1 | 0.944 | 4.492 | 3.34 |
| 10 | 1.166 | 3.855 | 2.33 |
| 50 | 1.682 | 2.123 | 0.61 |
| 200 | 2.038 | 0.926 | 0.25 |

请看这几个结果：

- **第一步之后，损失从 44 降到 3.3。** 起点离碗底很远。坡很陡，梯度很大，所以第一步走得很远。
- **之后的步子越来越小。** 接近碗底时，坡变缓。梯度变小，步子也变小。
- **训练停在 a ≈ 2.04、b ≈ 0.93，不是正好 2 和 1。** 原因是数据里有噪声。最小二乘的解析解（`np.polyfit`）是 a = 2.052、b = 0.879。梯度下降正朝同一个点移动。

> **注意：**线性回归有解析解，为什么还要用梯度下降？因为只有线性模型有解析解。从第 3 章的神经网络开始，没有公式能一步给出答案。梯度下降是唯一通用的方法。这一章在一个答案已知的问题上使用它。这样我们能看清它怎样工作。

## 6. 学习率：太小、合适、太大

学习率是训练中最重要的设置。运行：

```bash
uv run python chapters/01-linear-regression/code/02_learning_rate.py
```

输出（每个学习率都走 100 步）：

| 学习率 η | 100 步后的损失 | 结果 |
|---:|---:|---|
| 0.005 | 2.34 | 太小：方向正确，但太慢 |
| 0.05 | 0.29 | 正常收敛 |
| 0.0914 | 0.25 | 接近临界值，收敛最快 |
| 0.1066 | 7.7 × 10⁹ | 太大：参数来回震荡，步子越来越大，最后发散 |

临界值从哪里来？在这个问题里，损失是 `a` 和 `b` 的二次函数。碗的形状只由数据决定。对二次函数，只有在 `η < 2/λ_max` 时梯度下降才收敛。这里的 `λ_max` 是 Hessian（损失的二阶导数矩阵）的最大特征值。它表示碗在最陡方向上弯得有多厉害。代码算出的临界值是 0.1016。实验和理论一致：学习率比它小一点就收敛，比它大一点就发散。

后面的章节还会遇到这个现象。大模型训练时损失突然上升（loss spike），原因常常是某个方向上的一步太大。第 6 章介绍 warmup 和学习率衰减。这两种方法都在控制这个设置。

## 7. 小结

- **模型**：`ŷ = a·x + b`。参数是 `a` 和 `b`。
- **损失**：均方误差 `L(a, b)`。数据不变时，损失是参数的函数。
- **梯度**：`∂L/∂a` 和 `∂L/∂b`。梯度指向损失上升最快的方向。
- **更新**：`参数 ← 参数 − η · 梯度`。重复更新，直到损失不再下降。
- **学习率**：太小，训练慢；太大，训练发散。

## 从极简代码到生产级代码

极简代码里的梯度公式是我们手工推导的。真实的深度学习代码不这样写。模型一复杂，手工推导的工作量太大，也容易出错。同一个任务的 PyTorch 标准写法在 [`code/03_pytorch_version.py`](code/03_pytorch_version.py)：

```python
model = nn.Linear(in_features=1, out_features=1)   # the weight is a, the bias is b
optimizer = torch.optim.SGD(model.parameters(), lr=0.05)
loss_fn = nn.MSELoss()

for step in range(201):
    y_hat = model(x)              # 1. forward pass: calculate the predictions
    loss = loss_fn(y_hat, y)      # 2. loss
    optimizer.zero_grad()         # 3. set the gradients from the last step to zero
    loss.backward()               # 4. backward pass: autograd calculates the gradients
    optimizer.step()              # 5. update the parameters
```

下表列出生产级代码多做了什么，以及原因：

| 极简代码 | 生产级代码 | 原因 |
|---|---|---|
| 手工推导 `∂L/∂a` 和 `∂L/∂b` | `loss.backward()` 计算梯度 | 几十亿个参数无法手工推导梯度。第 4 章你会自己实现 autograd，看清它的原理。 |
| `a = a - lr * grad_a` | `optimizer.step()` | 更新规则会变复杂（第 6 章的 AdamW）。由优化器在一个地方统一管理。 |
| 两个浮点数 `a` 和 `b` | `nn.Linear` 里的权重张量 | 第 2 章把一个输入扩展为多个输入。权重随之变成矩阵。 |
| 无 | `optimizer.zero_grad()` | PyTorch 默认把新梯度**加到**旧梯度上。第 14 章的梯度累积会用到这个特性。所以每一步开始前要把梯度清零。 |

脚本最后比较 PyTorch 的结果和手工梯度的结果。201 步之后，两者都是 `a = 2.039, b = 0.925`，**每一位都相同**。之后的每一章都做同样的检查：生产级代码必须和极简代码给出相同的结果（对拍）。结果一致，才能信任生产级代码。

请记住这个五行的训练循环。第 14 章预训练主线模型时，循环外面会多出一些工程部分：分布式训练、混合精度、从 checkpoint 续训。但循环的结构仍然是这五步。
