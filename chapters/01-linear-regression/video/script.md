## 二、分镜与旁白

### S01 片头
- 画面：黑底，章节标题卡淡入："第 1 章 / y = ax + b / From 0 to AGI"。
- 屏幕文字：第 1 章 · y = ax + b
- 旁白：欢迎来到 From 0 to AGI。这门课的终点，是几十亿参数的大语言模型；起点，是一条直线。这一章我们只做一件事：用最简单的模型，把"训练"这个词彻底讲清楚。

### S02 问题：一堆点
- 画面：坐标系出现，50 个蓝色数据点逐个出现，大致排成一条斜线。
- 屏幕文字：给定数据 (x, y)，找一条最合适的直线
- 旁白：假设我们手里有一批数据，每个点是一对 x 和 y。比如 x 是房子的面积，y 是价格。把它们画出来，大致排成一条斜线，但又不完全在线上，因为现实数据总有噪声。我们的问题是：给一个新的 x，怎么猜出它的 y？

### S03 模型：ŷ = ax + b
- 画面：公式 ŷ = ax + b 出现，a、b 标成橙色；一条绿色直线随 a、b 变化而旋转、平移。
- 屏幕文字：模型 ŷ = a·x + b；参数：a（斜率）、b（截距）
- 旁白：最简单的猜法是画一条直线：{ŷ 等于 a x 加 b|y hat 等于 a 乘 x 加 b}。{ŷ|y hat} 是模型的预测，a 是斜率，b 是截距。a 和 b 叫作模型的参数，模型知道的一切，都装在这两个数里。改变 a，直线会转动；改变 b，直线会上下平移。所谓训练，就是让数据来决定 a 和 b 该取多少。

### S04 损失：猜得有多差
- 画面：固定一条很差的直线，每个点到直线画一条红色竖线（残差）；然后 MSE 公式出现。
- 屏幕文字：损失 L(a, b) = 1/N · Σ (a·xᵢ + b − yᵢ)²
- 旁白：要改进，先得知道现在有多差。每个点的预测值减去真实值，叫作残差，就是图上这些红线。把所有残差平方，再取平均，就得到均方误差，这就是我们的损失。平方有两个好处：正负误差不会互相抵消，而且函数处处光滑，方便求导。注意，数据是固定的，损失是参数 a 和 b 的函数。

### S05 损失是一个碗
- 画面：右侧画出损失关于 (a, b) 的等高线图，最低点用黄色标出。
- 屏幕文字：每一组 (a, b) 对应一个损失值 → 一个"碗"
- 旁白：如果把每一组 a 和 b 对应的损失都算出来，画成等高线图，会得到一个碗的形状。碗底那一点，就是损失最小的 a 和 b。训练的目标，就是找到碗底。

### S06 梯度：脚下的坡度
- 画面：等高线图上一个点，画出红色梯度箭头（指向上坡）和反方向的箭头；下方出现两个偏导公式。
- 屏幕文字：∂L/∂a = 2/N · Σ (ŷᵢ − yᵢ)·xᵢ　　∂L/∂b = 2/N · Σ (ŷᵢ − yᵢ)
- 旁白：想象你站在山坡上，四周全是雾，看不到谷底。你能做的，只是感受脚下的坡度，然后往最陡的下坡方向迈一步。这个坡度，就是梯度。它由损失对每个参数的偏导数组成，指向损失上升最快的方向。对均方误差，梯度可以直接算出来。这两个公式其实很好懂：模型整体猜高了，b 的梯度就是正的，说明 b 应该调小。

### S07 梯度下降
- 画面：左边数据图里直线逐步转到正确位置；右边等高线图上一串点从起点走向碗底；下方表格实时显示步数、a、b、损失。
- 屏幕文字：a ← a − η·∂L/∂a　　b ← b − η·∂L/∂b
- 旁白：梯度指向上坡，我们就往反方向走一小步，这叫梯度下降。{η|eta} 是学习率，控制步子迈多大。我们从一个很差的起点出发：a 等于负一，b 等于四，损失是四十四。只走一步，损失就掉到了三点三。之后越走越慢，因为越接近谷底，坡越缓，梯度越小。两百步之后，a 大约是二点零四，b 大约是零点九三，损失停在零点二五左右。它不会降到零，因为数据本身有噪声。你可以对照左边的图：参数每走一步，数据图里的直线就转动一点，越来越贴近这些点。

### S08 为什么不直接用公式算
- 画面：左边是梯度下降的终点 a≈2.04、b≈0.93，右边是 np.polyfit 的解析解 a=2.052、b=0.879；然后画面切到一个复杂的曲线，打上问号。
- 屏幕文字：线性模型有解析解，神经网络没有
- 旁白：你可能会问：直线拟合明明有现成的公式，一步就能算出最优的 a 和 b，为什么要一步一步地走？确实，最小二乘的解析解是 a 等于二点零五，b 等于零点八八，梯度下降正在朝它收敛。但只有线性模型这么幸运。从第三章的神经网络开始，就再也没有一步到位的公式了。梯度下降是唯一通用的办法。今天用它解一个我们知道答案的问题，就是为了看清它是怎么工作的。

### S09 学习率：太小、刚好、太大
- 画面：三个并排的小等高线图，分别展示 η=0.005（爬得很慢）、η=0.05（顺利到底）、η=0.1066（来回震荡、越跳越远）。
- 屏幕文字：η 太小：慢　　η 合适：收敛　　η 太大：发散
- 旁白：学习率是训练里最重要的旋钮。太小，方向是对的，但走得很慢，一百步之后还在半山腰。合适，稳稳走到谷底。太大，一步迈过了谷底，落到对面更高的地方，下一步梯度更大，步子更大，来回震荡，越跳越远，损失爆炸到几十亿。

### S10 临界学习率
- 画面：一条数轴，标出临界值 0.1016；左边绿色"收敛"，右边红色"发散"；两个实验点 0.0914 和 0.1066 落在两侧。
- 屏幕文字：收敛条件 η < 2/λmax ≈ 0.1016
- 旁白：这个"合适"其实可以算出来。对这种碗形的二次函数，梯度下降收敛的条件是，学习率小于二除以{λmax|lambda max}，也就是碗最陡的方向弯得有多厉害。代码算出临界值是零点一零一六。学习率比它小一点，收敛；比它大一点，发散。理论和实验完全吻合。

### S11 从极简到生产级
- 画面：左边是手算梯度的几行 NumPy 代码，右边是 PyTorch 五行训练循环，逐行高亮：前向、损失、清梯度、反向、更新。
- 屏幕文字：PyTorch 标准写法：五行训练循环
- 旁白：真实的深度学习代码不会手推梯度。同一件事用 PyTorch 写，就是这五行：前向算预测，算损失，清掉上一步的梯度，反向传播自动求梯度，优化器更新参数。我们把两种写法放在一起跑，两百零一步之后，结果逐位一致。以后每一章，生产级代码都要和极简代码这样对拍。

### S12 这和大模型有什么关系
- 画面：四个方块"模型 → 损失 → 梯度 → 更新"连成一个循环；旁边小字：参数 2 个 → 几十亿个。最后出现"下一章：从标量到矩阵"。
- 屏幕文字：模型 → 损失 → 梯度 → 更新（循环）
- 旁白：记住这四步：模型、损失、梯度、更新。训练一个大语言模型，结构上和今天做的事一模一样，只是参数从两个变成了几十亿个，损失从均方误差变成了预测下一个词的交叉熵。下一章，输入从一个数变成一组数，参数从两个数变成一个矩阵。最后再回顾一遍：模型给出预测，损失衡量错得多离谱，梯度指出参数该往哪边动，更新让参数真的动一小步。整门课里，这四步会反复出现。我们下一章见。
