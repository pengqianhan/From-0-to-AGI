## 二、分镜与旁白

### S01 片头
- 画面：标题卡"第 8 章 / 注意力 / From 0 to AGI"，副标题"让每个位置自己决定看哪里"。
- 屏幕文字：第 8 章 · 注意力
- 旁白：上一章我们做了一个 bigram 语言模型，它猜下一个字的时候，只看前一个字。这一章我们要让模型看见整段前文，而且让它自己决定该看哪里。这个机制叫注意力，它是今天所有大语言模型的核心。

### S02 只看前一个字不够
- 画面：一行字符 "hear me speak"，最后一个位置只有一根箭头连到前一个字符；然后更多箭头指向更早的字符，打上问号。
- 屏幕文字：bigram 只看前一个 token → 要看整段前文
- 旁白：想猜 speak 后面是什么，只看最后一个字母 k 显然不够。第七章的 bigram 只记得 k 后面常跟什么。前面的 hear me 也有用：谁在说话，在说什么。问题是，前文长度不固定，怎么把一整段前文变成一个向量，交给后面去预测？

### S03 RNN：一个固定大小的口袋
- 画面：一串方块从左到右依次点亮，每个方块把新字符和旧状态合成新状态 h；右侧标注"固定大小"、"只能一步一步算"。
- 屏幕文字：RNN：前文全部压进一个固定大小的状态，顺序计算
- 旁白：以前的做法是循环神经网络，简称 RNN。它从左往右读，每读一个字，就把新信息揉进一个固定大小的状态里。这有两个麻烦：第一，前文再长，也得挤进同样大小的口袋，早期的信息容易被冲掉；第二，第十个字必须等前九个算完，没法并行。注意力换了个思路：不压缩，每个位置直接去看前面所有位置。

### S04 最朴素的办法：取平均
- 画面：左边 5 个彩色 token 向量（二维箭头），右边下三角权重矩阵 W 逐行出现（1；1/2 1/2；…），W 乘 X 得到前缀平均，最后一行的平均向量画在左图里。
- 屏幕文字：前缀平均 = 下三角矩阵 W 乘 X
- 旁白：最朴素的办法是：把前面所有字的向量取平均。第五个位置，就是前五个向量各乘五分之一再相加。有一个经典技巧：把这些权重排成一个下三角矩阵，每行加起来等于一，一次矩阵乘法，就同时算出了每个位置的平均。上三角全是零，意思是不能看未来。我们用代码验证过，它和一个个循环去算的结果完全一样。

### S05 让权重由数据决定
- 画面：同一组向量，权重矩阵换成点积分数 x·xᵀ，经过 softmax 后每行不再均匀；最后一行的加权平均向量明显偏向某个向量。
- 屏幕文字：权重 = softmax(相似度)；相似度 = 点积
- 旁白：可是平均有个毛病：每个字一样重要。其实有的字很关键，有的字无关紧要。那就让权重由数据决定。第二章说过，两个向量方向越一致，点积越大，所以就用点积衡量相关程度，再用第五章的 softmax 把分数变成加起来等于一的权重。不过直接拿向量和自己做点积，有个问题：自己和自己的点积往往最大，五个位置里五个都最关注自己，最后一行有零点七五的权重落在自己身上。

### S06 Q、K、V：三个投影
- 画面：输入 X 分出三条支路，分别乘 Wq、Wk、Wv 得到 Q、K、V；旁边三行说明："Q：我在找什么"、"K：我有什么"、"V：我提供什么"。
- 屏幕文字：Q = XWq，K = XWk，V = XWv
- 旁白：解决办法是，给每个字准备三个不同的向量，都是第二章学过的线性变换，X 乘一个矩阵。查询 Q，表示我在找什么；键 K，表示我有什么特征；值 V，表示如果你关注我，我交给你什么。位置 t 对位置 s 的分数，就是 t 的查询和 s 的键做点积。这样，一个字就可以去找和自己不一样的字了。这三个矩阵都是训练出来的参数。

### S07 分数、mask、softmax
- 画面：训练好的模型在 "speak." 上的一个头：6×6 分数矩阵 {QKᵀ|Q 乘 K 的转置} 按行填入数字；上三角变灰（−∞）；每行经过 softmax 变成紫色深浅的权重；最后权重乘 V。
- 屏幕文字：softmax(QKᵀ/√d + mask) V
- 旁白：把所有查询和所有键一次算完，就是 {Q 乘 K 的转置|Q 乘 K 的转置}，一个 T 乘 T 的分数矩阵，第 t 行是位置 t 对每个位置的打分。这里是我们训练好的小模型，在 speak 这几个字符上的真实分数。语言模型预测下一个字时不能偷看后面，所以把上三角填成负无穷，这叫因果 mask。每一行做 softmax，负无穷变成零，其余变成加起来等于一的权重，颜色越深权重越大，每一行只有对角线和它左边的格子有颜色。最后，权重乘 V，就是按权重把值向量加权平均。

### S08 为什么除以 √d
- 画面：表格：d = 16、64、256、1024 时点积方差 15.9、64.7、254.4、1026.8，最大权重和有效个数；再显示缩放后方差都是 1.0。
- 屏幕文字：q·k 的方差 ≈ d；除以 √d 后 ≈ 1
- 旁白：公式里还有一个除以根号 d。d 是每个头的维度。如果 q 和 k 的每个分量都是方差为一的随机数，它们的点积是 d 项相加，方差就是 d。实测也是这样：d 等于一千零二十四时，方差大约一千。分数差得这么开，softmax 几乎把全部权重压到一个位置上，最大权重零点九六，梯度也跟着变小。除以根号 d，方差回到一，不管 d 多大，权重分布都差不多，十六个位置里平均有十个左右在分享权重。这正是原论文给出的理由。

### S09 对拍与因果性检验
- 画面：两行结果：从零实现 vs PyTorch 官方 {SDPA|S D P A}，最大差 9.7e-8；改掉后三个位置的输入，前五个位置输出变化 0。
- 屏幕文字：从零实现 = F.scaled_dot_product_attention(is_causal=True)
- 旁白：我们用 PyTorch 从零写了一遍注意力，和官方函数 scaled dot product attention 对拍，最大差不到一亿分之一。再做一个因果性检验：把最后三个位置的输入改掉，前五个位置的输出一点都不变。说明 mask 真的挡住了未来。有了这两条，后面的生产级代码就可以放心地用官方函数。

### S10 多头注意力
- 画面：一个宽度 C = 32 的向量切成 4 段，每段 8 维各自做注意力，得到 4 张不同的权重图，拼回 32 维，再乘 Wo；下方逐步显示形状 (B, T, C) → (B, H, T, d) → (B, H, T, T) → (B, T, C)。
- 屏幕文字：多头：切成 H 份各算注意力，拼回来再乘 Wo
- 旁白：一组权重只能表达一种看法。多头注意力把 C 维切成 H 份，每份 d 等于 C 除以 H 维，各自独立做一遍注意力，最后拼回来，再乘一个输出矩阵 Wo 混合一下。每个头有自己那一份 Wq、Wk、Wv，所以能学出不同的关注方式。原论文用了八个头，每个头六十四维。形状上，B 乘 T 乘 C 先变成 B 乘 H 乘 T 乘 d，权重是 B 乘 H 乘 T 乘 T，再拼回 B 乘 T 乘 C。参数量是四倍 C 的平方，和切成几个头无关。

### S11 训练一个单层注意力模型
- 画面：三根横条对比验证损失：bigram 2.487、均匀平均 2.463、注意力 2.083（nats/字符），旁边 bits-per-byte。
- 屏幕文字：Tiny Shakespeare 字符级 · 训练 2000 步 · 验证损失
- 旁白：来真的训练一下。在莎士比亚小语料上，训练三个只差一步的字符级模型：同样的数据、同样的优化器、同样的步数，唯一的区别是怎么混合前文。只看当前字符的 bigram，验证损失二点四九；加上均匀平均，看得到前文，只降到二点四六；换成注意力，降到二点零八，每个字节少用零点五八个比特。均匀平均多了八千个参数，几乎没带来什么；注意力再多八千个参数，效果就完全不同。看得见前文还不够，关键是会挑。

### S12 它到底在看哪里
- 画面：两张真实注意力热力图（紫色深浅），行是当前字符，列是被看的字符，文本 "further, hear me speak."：头 1 几乎全在对角线左边一格，头 0 在左边两格；下方标注各自的平均权重。
- 屏幕文字：训练好的模型的真实注意力权重
- 旁白：打开这个模型看看。行是当前字符，列是它看的字符，颜色越深，权重越大。第一个头几乎总是看前一个字符，平均六成二的权重给了它；而且它会看情况：一到空格，它就改看空格自己。另一个头主要看前两个字符。右上角一片空白，那是因果 mask。没人告诉它要这样分工，这是训练自己学出来的：多个头合起来，相当于它自己拼出了一个看前两三个字的模型。单层、两千步的小模型学不到语法，但已经发现：离得近的字最有用。

### S13 从极简到生产级
- 画面：`zero/model.py` 里 Attention.forward 的关键几行代码，逐行高亮：wq/wk/wv、q_norm/k_norm、apply_rope、kv_cache.update、F.scaled_dot_product_attention(enable_gqa)、wo；右侧标注"第 9 章""第 10 章""GPU 上是 FlashAttention（未在 GPU 验证）"。
- 屏幕文字：zero/model.py：Attention = 本章 + QK-Norm + RoPE + GQA + KV cache
- 旁白：主线模型里的注意力，骨架和我们写的一模一样：三个投影，缩放点积，因果 mask，多头，输出投影。它多了几样东西：对每个头的 q 和 k 做归一化，叫 QK-Norm；用旋转位置编码 RoPE，这两个第九章讲；让几个查询头共用一组 K 和 V，叫 GQA，第十章讲；还有推理用的 KV cache。计算交给 PyTorch 的官方函数，在 GPU 上会自动用 FlashAttention，这条路径我们还没在 GPU 上验证。把额外的部分关掉，它和我们的极简版最大差不到一亿分之一；整个模型和千问三的官方实现对拍，也由测试保证一致。

### S14 小结与下一章
- 画面：一条流程：X → Q、K、V → QKᵀ/√d → mask → softmax → 乘 V → 多头拼接 → Wo；最后出现"下一章：现代 Transformer"。
- 屏幕文字：注意力 = 由数据决定权重的加权平均
- 旁白：总结一下：注意力就是加权平均，权重由查询和键的点积决定，除以根号 d 保持稳定，因果 mask 挡住未来，多头让模型同时有几种看法。任意两个位置之间都是一步直达，不用像 RNN 那样一站一站地传。但光有注意力还不是一个完整的模型：它只会搬运和混合信息，自己几乎不做计算。下一章，我们给它配上前馈网络、归一化、残差和位置编码，搭出一个完整的现代 Transformer。
