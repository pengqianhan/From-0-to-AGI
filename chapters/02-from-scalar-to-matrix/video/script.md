## 二、分镜与旁白

### S01 片头
- 画面：章节标题卡淡入："第 2 章 / 从标量到矩阵 / From 0 to AGI"，副标题 y = XW + b。
- 屏幕文字：第 2 章 · 从标量到矩阵
- 旁白：上一章，我们用一条直线学会了训练的四个步骤：模型、损失、梯度、更新。但那个模型只有一个输入。这一章，我们把一个数换成一组数，把两个参数换成一个矩阵。你会看到，那四个步骤一个字都不用改。

### S02 一个输入不够
- 画面：左边第 1 章的 ŷ = ax + b，下面标"只看面积"；右边一张房子卡片：面积 80㎡、卧室 2 间、距市中心 5km；然后出现 ŷ = w₁x₁ + w₂x₂ + w₃x₃ + b。
- 屏幕文字：一个输入 → 三个输入
- 旁白：还是预测房价。第一章只看面积，但真实的房价还取决于有几间卧室、离市中心有多远。现在每套房子有三个输入：面积、卧室数、距离。三个输入就需要三个权重，每个权重说明这个特征对价格影响多大。模型变成了{ŷ 等于 w₁x₁ 加 w₂x₂ 加 w₃x₃ 加 b|y hat 等于 w 一乘 x 一，加 w 二乘 x 二，加 w 三乘 x 三，再加 b}。

### S03 向量与点积
- 画面：蓝色向量 x = [80, 2, 5] 与橙色向量 w = [0.8, 5, −3] 并排，对应元素连线相乘得 64、10、−15，求和 59，加 b = 20 得 79。
- 屏幕文字：点积 w · x = w₁x₁ + w₂x₂ + w₃x₃
- 旁白：把三个输入排成一列，叫作向量；三个权重也排成一个向量。对应位置相乘，再全部加起来，这个运算叫点积。算一个例子：面积八十乘零点八得六十四，两间卧室乘五得十，五公里乘负三得负十五，加起来是五十九，再加上偏置二十，预测七十九万。第一章的 a 乘 x，其实就是只有一个元素的点积。

### S04 一批样本：矩阵
- 画面：四套房子的向量一行行摞成矩阵 X（4×3），右边竖着的权重 W（3×1），等号后是四个预测值 [79, 125, 49, 104.5]。
- 屏幕文字：一次矩阵乘法 = 所有样本的点积
- 旁白：一套房子算一次点积。那一万套呢？把每套房子的向量当成一行，摞在一起，就得到一个矩阵 X。每一行是一个样本，每一列是一个特征。再把权重竖着放成一列 W，一次矩阵乘法，{X @ W|X 乘 W}，就同时算出了所有房子的预测。这里四套房子，一次得到四个价格。

### S05 矩阵乘法怎么算
- 画面：A（2×3）乘 B（3×2），依次高亮 A 的第 i 行和 B 的第 j 列，下方写出 1×7 + 2×9 + 3×11 = 58，结果矩阵 C 的格子逐个填上 58、64、139、154。
- 屏幕文字：C[i][j] = A 的第 i 行 · B 的第 j 列
- 旁白：矩阵乘法到底在算什么？结果里第 i 行、第 j 列的那个数，就是左边矩阵的第 i 行，和右边矩阵的第 j 列做点积。比如左上角：一乘七，加二乘九，加三乘十一，等于五十八。所有的行和所有的列两两做一次点积，就填满了整个结果。

### S06 形状规则
- 画面：三个长方块表示 (m,k)、(k,n)、(m,n)，中间两个 k 高亮后"消掉"；下方三个例子：(4,3)@(3,1)→(4,1) 可以；(32,128)@(128,64)→(32,64) 可以；(3,2)@(3,5) 报错。
- 屏幕文字：(m, k) @ (k, n) → (m, n)
- 旁白：由此得到这一章最重要的规则：左边矩阵的列数，必须等于右边矩阵的行数，因为做点积的两个向量必须一样长。写成形状就是，{(m, k) @ (k, n)|m 乘 k 的矩阵，乘以 k 乘 n 的矩阵}，得到 m 乘 n，中间的 k 被消掉了。四乘三乘以三乘一，得到四乘一；三乘二乘以三乘五，二和三对不上，直接报错。写深度学习代码，很多 bug 都是形状没对上，所以每一步都要在心里把形状过一遍。

### S07 y = XW + b 的每个字母
- 画面：公式 Y = XW + b，每个字母下面标形状：X (N, k)、W (k, n)、b (n,)、Y (N, n)；N 旁标"batch 维"；W 的每一列高亮为"一个输出"。
- 屏幕文字：Y = XW + b：(N, k) @ (k, n) + (n,) → (N, n)
- 旁白：现在给{Y = XW + b|Y 等于 X W 加 b}的每个字母标上形状。X 是 N 乘 k：N 是这一批有多少个样本，叫批量维度，也就是 batch；k 是输入特征数。W 是 k 乘 n，n 是输出的个数，W 的每一列负责算出一个输出。结果 Y 是 N 乘 n。注意，W 的形状和 N 无关：一次喂四个样本还是一万个样本，用的都是同一个 W。

### S08 广播：b 加到每一行
- 画面：左边 XW（4×2 的数字），上方一行 b = [1, −1]；b 向下复制出四行（虚线框），与 XW 相加得到结果矩阵；下方写广播规则。
- 屏幕文字：广播：b (n,) 自动加到每一行
- 旁白：那偏置 b 呢？它只有 n 个数，而 {XW|X W} 有 N 行。NumPy 和 PyTorch 会自动把 b 加到每一行上，就像把它复制了 N 份，但内存里并没有真的复制。这叫广播。规则是：形状从最后一维开始对齐，长度相等，或者其中一个是一，才能广播。如果 b 的长度和输出个数对不上，就会直接报错。

### S09 梯度也写成矩阵
- 画面：上方第 1 章的 ∂L/∂a = 2/N·Σ(ŷᵢ − yᵢ)xᵢ（灰色），下方矩阵形式 ∂L/∂W = 2/N·Xᵀ(ŷ − y)；再用长方块标出形状 (k, N) @ (N, 1) → (k, 1)，与 W 同形状。
- 屏幕文字：∂L/∂W = 2/N · Xᵀ(ŷ − y)
- 旁白：模型变成了矩阵，梯度也能写成矩阵。第一章里，a 的梯度是二除以 N，乘以残差和 x 的乘积之和。现在，所有权重的梯度一行就能写完：{∂L/∂W 等于 2/N 乘 Xᵀ(ŷ − y)|W 的梯度，等于二除以 N，乘以 X 的转置，再乘以残差}。检查一下形状：X 的转置是 k 乘 N，残差是 N 乘一，结果是 k 乘一，和 W 一模一样。梯度和参数永远同形状，因为每个参数都需要自己的梯度。

### S10 训练多元线性回归
- 画面：左边损失曲线（对数纵轴），从 7875 快速降到 21.9；右边表格：面积、卧室、距离、b 四行，"学到"一列随步数变化，旁边是"真实"一列。
- 屏幕文字：200 套房子 · 学习率 0.1 · 从全 0 出发
- 旁白：我们造了两百套房子，真实的规律是：每平米零点八万，每间卧室五万，离市中心每远一公里少三万，再加二十万和一些噪声。训练前先做一件小事：把每个特征减去均值、除以标准差，叫作标准化。不然面积的数值比卧室数大几十倍，碗会被压得又扁又陡，临界学习率会小到不到万分之一；标准化之后是零点八八。从全零出发，学习率零点一，损失从七千八百多，十步后降到一百一十二，五十步后稳定在二十一点九。换算回原来的单位，学到的是零点八一五、四点七三、负三点零七和十九点八四，和真实值很接近，也和最小二乘的解析解完全一致。

### S11 循环 vs 向量化
- 画面：三根横条表示同一次前向的耗时：Python 三重循环、每行一次 np.dot、一次 X @ W，旁边标毫秒数和倍数；下方一行训练 200 步的对比。
- 屏幕文字：同一个计算，三种写法
- 旁白：为什么非要写成矩阵？除了公式简洁，还因为快。同样算一次一千乘一百、乘以一百乘十的前向，Python 三重循环要几十毫秒；每个样本调用一次 NumPy 点积，快了几十倍；而一次 {X @ W|X 乘 W}，不到零点一毫秒，快了上千倍。训练也一样，五千套房子训练两百步，循环写法要半秒以上，矩阵写法快了几十倍。三种写法算出来的结果完全一致。

### S12 为什么快
- 画面：左框"Python 循环：每次乘加都要 解释 → 查类型 → 建对象"，右框"X @ W：整块交给 BLAS：连续内存、SIMD、多核"；下方一行"GPU：成千上万个核心同时做乘加"。
- 屏幕文字：向量化 = 把循环交给底层库
- 旁白：快在哪里？Python 循环每做一次乘法，都要解释一行代码、检查类型、创建新的对象，真正的计算只占很小一部分。{X @ W|X 乘 W} 则把整块数据交给用 C 和汇编写好的矩阵库，叫作 BLAS。数据在内存里连续存放，一条 CPU 指令能同时算好几个数，还能用上多个核心。到了 GPU 上，成千上万个核心一起做乘加，而它们最擅长的恰恰就是矩阵乘法。大模型里绝大部分计算都是矩阵乘法，这就是为什么整个深度学习都写成矩阵的形式。

### S13 从极简到生产级
- 画面：左边手写矩阵梯度的 NumPy 代码，右边 nn.Linear(3, 1) + 第 1 章的五行训练循环；标注 weight 形状 (1, 3)、前向 = x @ weight.T + bias；最后一行对拍结果。
- 屏幕文字：PyTorch 标准写法：nn.Linear + 同样的五行
- 旁白：PyTorch 的标准写法是 {nn.Linear|n n 点 Linear}。{nn.Linear(3, 1)|n n 点 Linear 三逗号一} 就是一个三进一出的线性层，一次吃进一整批数据：两百乘三进去，两百乘一出来。有个小细节：PyTorch 把权重存成一乘三，也就是输出乘输入，所以前向算的是 x 乘以权重的转置，再加偏置。训练循环还是第一章那五行，一个字没改，梯度交给自动微分。和手写矩阵梯度的 NumPy 版一起跑两百步：用双精度，两边的差是零；用 PyTorch 默认的单精度，差在十万分之二左右。

### S14 小结与下一章
- 画面：左边三行小结（向量与点积、矩阵与形状规则、广播）；右边 W1 (3×2) @ W2 (2×1) = W (3×1) 的方块合并动画，然后一条弯曲的数据点和一条拟合不上的直线，最后出现"下一章：非线性与神经网络"。
- 屏幕文字：两层线性 = 一层线性 → 需要非线性
- 旁白：总结一下。一个输入变成一组，就是向量和点积；一批样本摞起来，就是矩阵；{Y = XW + b|Y 等于 X W 加 b}，N 乘 k 乘以 k 乘 n，得到 N 乘 n，偏置靠广播加到每一行。训练的四个步骤一个没变。最后留一个问题：把两个线性层叠起来，会不会更强？代码告诉我们不会，{W1 @ W2|W 一乘 W 二} 还是一个矩阵，两层合起来就等于一层。线性函数叠多少层都是线性的，拟合不了一条曲线。下一章，我们给它加上一点非线性，这就是神经网络。
