## 二、分镜与旁白

### S01 片头
- 画面：章节标题卡淡入："第 9 章 / 现代 Transformer / From 0 to AGI"，副标题"把注意力搭成一个会写字的模型"。
- 屏幕文字：第 9 章 · 现代 Transformer
- 旁白：上一章我们推出了注意力。但一层注意力还不是语言模型。这一章，我们把注意力装进一个完整的模型，装上今天几乎所有开源大模型都在用的零件，然后在笔记本电脑的 CPU 上训练它，看它从乱码学会写剧本。

### S02 全景：查表、N 个 Block、打分
- 画面：自下而上逐块搭出模型：token id → Embedding → Block × N → RMSNorm → LM head → 下一个字节的概率。
- 屏幕文字：查表 → N 个 Block → 打分
- 旁白：整个模型只做三件事。第一，查表：每个字节的编号去一张表里取出一行，变成一个向量。第二，把这些向量送过 N 个一模一样的 Block。第三，打分：最后一个向量乘上输出矩阵，得到下一个字节的二百五十六个分数，softmax 之后就是概率。

### S03 Block 内部：Pre-Norm 加残差
- 画面：Block 展开：一条竖直的"残差流"主干道；左侧支路 RMSNorm → 注意力 → 加回；再一条支路 RMSNorm → FFN → 加回。两行公式出现。
- 屏幕文字：x = x + Attn(RMSNorm(x))　x = x + FFN(RMSNorm(x))
- 旁白：每个 Block 里有两个子层。注意力负责在位置之间交换信息，前馈网络负责在每个位置内部加工。它们都包在同一个套路里：先 RMSNorm，算出一点修改意见，再加回主干道。这条主干道叫残差流，它的形状从头到尾不变。归一化放在子层入口，叫 Pre-Norm，第六章讲过，这样几十层也训得动。

### S04 问题：注意力分不清顺序
- 画面：两行字块"狗 咬 人 了"与"人 咬 狗 了"，箭头都汇向"了"；右侧显示两个输出向量的最大差 5.96e-08，然后加 RoPE 后变成 0.133。
- 屏幕文字：没有位置信息：前文只是一个集合
- 旁白：先解决一个问题。注意力只看内容像不像，不看位置。我们把"狗咬人了"和"人咬狗了"送进同一个注意力层，最后一个字"了"的输出，差别只有十的负八次方，就是浮点误差，完全一样。对它来说，谁咬谁没有区别。加上接下来要讲的 RoPE 之后，差别变成了零点一三。

### S05 RoPE：按位置旋转
- 画面：一个单位圆。橙色向量 q 在位置 m 转过 m·ω，蓝色向量 k 在位置 n 转过 n·ω，两者夹角标出；m、n 同时加 7，两个向量一起转，夹角不变；右侧表格列出 (3,1)、(10,8)、(50,48) 的点积都是 2.4426。
- 屏幕文字：RoPE：q、k 按位置旋转 → 点积只剩 m − n
- 旁白：{RoPE|肉普}，旋转位置编码，想法很几何。把 q 和 k 的维度两两配对，每一对看成平面上的一个箭头。在第 m 个位置，就把箭头转 m 乘 {ω|欧米伽} 的角度。两个箭头的点积，只取决于它们之间的夹角。q 转了 m 份，k 转了 n 份，夹角只和 m 减 n 有关。你看，位置三和一、十和八、五十和四十八，相隔都是二，点积都是二点四四二六。绝对位置被消掉了，只剩相对距离。而且旋转不改变长度，只改方向。

### S06 不同的转速
- 画面：四个小圆盘并排，指针分别以每步 1、0.1、0.01、0.001 弧度的速度转动，位置计数器从 0 走到 60。
- 屏幕文字：ω_i = 10000^(−2i/d)：秒针、分针、时针
- 旁白：不同的维度对转得快慢不同。第一对每前进一个位置转一弧度，像秒针；后面的一对比一对慢十倍，像分针和时针。快的分辨近处，慢的分辨远处，合起来就能分清几千个位置。RoPE 没有任何要学的参数，只加在 q 和 k 上。

### S07 SwiGLU：门控前馈
- 画面：输入 x 分成两路：W_gate → SiLU 曲线（门），W_up（内容），⊙ 相乘，再 W_down。右侧一个小柱状图显示门把一些维度关掉。下方显示参数对比：4d MLP 13.11M vs SwiGLU 8/3·d 13.11M。
- 屏幕文字：FFN(x) = W_down( SiLU(W_gate x) ⊙ W_up x )
- 旁白：注意力把信息搬过来，加工在前馈网络里。现代模型用的是 {SwiGLU|swi glu}。输入分成两路，一路是内容，一路过 {SiLU|sigh lu} 当作门，两路逐元素相乘，门接近零的维度就被关掉。关不关由输入自己决定。多了一个矩阵，所以中间宽度从四倍缩到大约三分之八倍，参数量正好持平：在宽度一千二百八十时，两种写法都是一千三百一十一万个参数。

### S08 QK-Norm：给注意力分数上保险
- 画面：两排柱状图（16 个位置的注意力权重）：上排"不加 QK-Norm"，随放大倍数 1 → 4 → 16 逐渐变成一根高柱；下排"加 QK-Norm"始终平缓。旁边显示平均最大权重 0.222 → 0.923 → 1.000 与 0.213。
- 屏幕文字：QK-Norm：点积之前，对每个头的 q、k 做 RMSNorm
- 旁白：训练中 q 和 k 的长度会慢慢变大，注意力分数跟着变大，softmax 就会一边倒。我们把同一组 q、k 放大四倍，平均来看，百分之九十二的注意力压在一个位置上；放大十六倍，几乎是百分之百。这样的梯度又尖又不稳定。QK-Norm 的办法很简单：做点积之前，先对每个头的 q 和 k 做一次 RMSNorm。不管放大多少倍，分布都不变。千问三、{Gemma|杰玛} 三、{OLMo|欧莫} 二都这样做。

### S09 共享 embedding
- 画面：左边输入表 V×d，右边输出头 d×V，一条弧线把两者连起来变成同一块；下方条形图：Qwen3-0.6B 总参数 596M 中词表矩阵 156M（26.1%），主线 690M 中 84M（12.2%）。
- 屏幕文字：输入表与输出头共用一个矩阵
- 旁白：模型两头各有一个词表大小的矩阵：输入时查表，输出时打分。共享 embedding 让它们用同一个矩阵。对小模型来说这很划算：千问三零点六 B 的词表矩阵有一亿五千六百万参数，占全部的百分之二十六，不共享就要再多出这么多。所以小模型普遍共享，大模型大多不共享。

### S10 完整张量形状数据流
- 画面：以主线模型尺寸，一行行出现形状并有高亮块沿着流动：(8, 4096) → (8, 4096, 1280) → q (8, 16, 4096, 128) / k v (8, 8, 4096, 128) → 分数 (8, 16, 4096, 4096) → (8, 4096, 1280) → FFN (8, 4096, 3584) → (8, 4096, 1280) → logits (8, 4096, 65536)。
- 屏幕文字：主线模型一次前向（B=8, T=4096）
- 旁白：把零件串起来，看主线模型一次前向的形状。八条序列、每条四千零九十六个 token，查表后变成宽一千二百八十的向量。进入注意力，q 拆成十六个头，k 和 v 只有八个头，这是第十章要讲的 {GQA|G Q A}。注意力分数是四千零九十六乘四千零九十六的方阵。前馈网络先变宽到三千五百八十四，再变回来。残差流的形状始终不变。最后的 logits 有二十一亿个数，按单精度存要八个 GB，词表越大，这一步越贵。

### S11 训练：从乱码到剧本
- 画面：左侧坐标系画出验证集 bit/字节曲线（8.05 → 2.22，7 个点）；右侧先显示训练前的乱码样本，再换成训练后的剧本样本。
- 屏幕文字：84 万参数 · 1200 步 · 验证集 2.22 bit/字节
- 旁白：现在训练。数据是莎士比亚的剧本，按字节切分。模型只有八十四万个参数。一开始是八点零五比特每字节，等于瞎猜。两百步之后降到二点七八，一千二百步之后是二点二二。训练前，它写出来的是乱码。训练后，它学会了剧本的格式：角色名、冒号、换行，大部分单词拼对了，还会用 thou 和 thy。意思还不太通，但已经像模像样。

### S12 两层对拍
- 画面：三个方框：极简模型（200 行）→ zero.Transformer → transformers 官方 Qwen3，箭头上标"权重原样搬运"和"export_to_hf_qwen3"；下方显示最大差 1.43e-05、贪心生成完全相同、pytest 8 passed，以及生产级训练命令。
- 屏幕文字：极简版 = zero = Qwen3
- 旁白：最后是本课的招牌动作：对拍。我们把这个两百行的模型权重原样搬进主线模型的生产级代码 zero，同一段文字的 logits，最大差只有十的负五次方，贪心生成的八十个字节一字不差。再把 zero 导出成千问三的格式，用官方实现读回来，结果还是一样。所以 zero 就是一个千问三结构的实现，我们的小模型，是一个四层的迷你千问三。生产级代码多做的，是配置驱动、分组查询注意力、KV cache 和分布式训练。

### S13 历史对照与下一章
- 画面：两列对照表：GPT-2 vs 今天（LayerNorm → RMSNorm、学出来的位置表 → RoPE、GELU MLP → SwiGLU、无 → QK-Norm）；然后生成动画：每出一个字节，整段重新计算一次（高亮整行反复闪），最后出现"下一章：推理与 KV cache"。
- 屏幕文字：GPT-2 → 现代 Transformer；下一章：KV cache
- 旁白：和二零一九年的 GPT-2 比，归一化从 LayerNorm 换成了 RMSNorm，位置从学出来的表换成了 RoPE，前馈网络从 GELU 换成了 SwiGLU，注意力前多了 QK-Norm。但骨架没变：查表、N 个 Block、打分。最后看一眼生成过程：每写一个字节，模型都把前面整段重新算一遍，大部分是上一步刚算过的。下一章，我们把算过的东西存起来，这就是 KV cache。
