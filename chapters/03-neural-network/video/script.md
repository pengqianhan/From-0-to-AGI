## 二、分镜与旁白

### S01 片头
- 画面：章节标题卡淡入："第 3 章 / 非线性与神经网络 / From 0 to AGI"，副标题"用折线拼出曲线"。
- 屏幕文字：第 3 章 · 非线性与神经网络
- 旁白：欢迎回来。前两章，我们用梯度下降训练了直线，又把输入从一个数扩展成一组数，模型写成了 X 乘 W 加 b。但它始终是线性的。这一章要解决的问题是：数据是弯的，直线拟合不了，怎么办？答案就是神经网络。

### S02 直线拟合不了曲线
- 画面：左侧坐标系，100 个蓝点画出 y = sin(2x)；绿色的最好直线出现，红色残差竖线；右侧显示 MSE。
- 屏幕文字：最好的直线：MSE = 0.4341
- 旁白：这是本章的数据：x 从负三到三，y 等于 sin 2x，一条上下起伏的波浪线。用第一章的方法，找所有直线里损失最小的那一条，就是这条几乎躺平的绿线。它的均方误差是零点四三，而直接猜平均值也不过零点五二。不是训练得不够，也不是学习率没调好，而是直线这个模型本身就弯不过来。第一章留下的问题就在这里：数据是更复杂的曲线时，难道要一个个去猜公式吗？

### S03 多叠几层线性层？
- 画面：公式逐步变形：(XW1 + b1)W2 + b2 → X(W1W2) + (b1W2 + b2) → XW + b，W1W2 和 b1W2+b2 用框标出。
- 屏幕文字：两层线性 = 一层线性
- 旁白：一个很自然的想法是：一层不够，那就多叠几层。第一层算 X 乘 W1 加 b1，第二层再乘 W2 加 b2。可是把括号展开，X 乘的是 W1 乘 W2，常数项是 b1 乘 W2 加 b2。W1 乘 W2 还是一个矩阵，后面那串也还是一个向量。所以两层线性层，等于一层线性层。叠多少层都一样，最后还是 X 乘 W 加 b。

### S04 用数字验证
- 画面：左侧：两层线性网络的训练损失曲线，很快压到虚线 0.4341 上不再下降；右侧：三行数字（25 个参数 / 97 个参数 / 差 1e-15）。
- 屏幕文字：25 个参数 → 还是直线；训练到 0.4341 就停住
- 旁白：用代码验证一下。随机造一个一到八再到一的两层线性网络，有二十五个参数；逐层算和合并成一层算，最大差只有十的负十六次方，就是浮点误差。三层、九十七个参数，也一样。再用梯度下降真的训练一个两层线性网络，损失一千步就降到零点四三四一，然后纹丝不动，和那条最好的直线分毫不差。参数再多，也逃不出直线。

### S05 激活函数：ReLU
- 画面：左侧坐标画出 ReLU 折线，负半边红色压平、正半边绿色；右侧公式 ReLU(z) = max(0, z)。
- 屏幕文字：ReLU(z) = max(0, z)
- 旁白：问题出在"全是线性"。解决办法出奇地简单：在两层之间，给每个数过一道非线性的函数，叫激活函数。最常用的一个叫 {ReLU|瑞 L U}，意思是修正线性单元：小于零的数变成零，大于零的数原样保留。就这么一个折角，线性层就再也合并不起来了，因为折角没法用一个矩阵乘法表示。注意，它作用在每个数上，各管各的，不会把不同的数混在一起。

### S06 其他激活函数
- 画面：四个小坐标系：sigmoid、tanh（灰色标"历史"）、SiLU、GELU（标"现代"），每个画出曲线；底部一行字：SwiGLU = 门控 + SiLU → 第 9 章。
- 屏幕文字：早期：sigmoid、tanh　现代：SiLU、GELU
- 旁白：激活函数不止一种。早期的神经网络常用 {sigmoid|sig moid} 和 {tanh|tan h}，它们是平滑的 S 形，把输入挤到一个范围里，但两头太平，梯度很容易变得几乎为零。{ReLU|瑞 L U} 在二〇一〇年前后流行起来，简单，正半边梯度恒为一。今天的大模型用的是它的平滑版本：{SiLU|S I L U} 和 {GELU|G E L U}。像千问、{DeepSeek|deep seek}、{Llama|拉玛} 的前馈层用的 {SwiGLU|swi G L U}，里面就是 {SiLU|S I L U}，第九章会讲。

### S07 两层 MLP 的结构
- 画面：左侧网络示意图：1 个输入 x（蓝）→ H 个隐藏单元（每个里面一个小 ReLU 折线）→ 1 个输出 ŷ（绿），连线是权重（橙）；右侧三行公式和形状。
- 屏幕文字：Z = XW1 + b1　A = ReLU(Z)　Ŷ = AW2 + b2
- 旁白：把线性层、激活函数、线性层串起来，就得到最简单的神经网络：两层的多层感知机，英文缩写 {MLP|M L P}。输入是 N 行一列，第一层把每个 x 变成 H 个数，形状变成 N 乘 H；每个数过一遍 {ReLU|瑞 L U}；第二层再把 H 个数加权求和，变回 N 乘 1。中间这 H 个数叫隐藏单元，也常叫神经元，H 就是网络的宽度。参数一共是 W1、b1、W2 各 H 个，再加一个 b2，也就是三 H 加一个。

### S08 一个隐藏单元 = 一个折点
- 画面：一个坐标系里画 v·ReLU(w·x + b)：一条折线；调 b，折点左右滑动；调 w，斜率变化；调 v 为负，折线翻下去。折点处黄色圆点，旁边标 x = −b/w。
- 屏幕文字：v · ReLU(w·x + b)：折点在 x = −b/w
- 旁白：一个隐藏单元到底在做什么？只看一个：先算 w 乘 x 加 b，过 {ReLU|瑞 L U}，再乘上第二层的权重 v。画出来是一条折线：一边是平的，一边是斜的。折点的位置在负 b 除以 w。改 b，折点左右滑动；改 w，斜的那一边变陡或变缓；v 取负数，整条折线翻下去。每个隐藏单元，就贡献这样一个折。

### S09 用折线拼形状
- 画面：先 ReLU(x) 与 ReLU(−x) 两条折线，相加成 |x|；再三条折线 ReLU(x+1)、−2ReLU(x)、ReLU(x−1) 相加成一个帐篷。
- 屏幕文字：|x| = ReLU(x) + ReLU(−x)　帐篷 = 三个 ReLU 相加
- 旁白：折线可以相加。两个 {ReLU|瑞 L U}，一个朝右，一个朝左，加起来就是绝对值，一个 V 字。三个 {ReLU|瑞 L U}，折点放在负一、零、一，中间那个乘负二，加起来是一个帐篷，别的地方都是零，只在中间鼓起一个包。有了帐篷，就能在任何位置堆出任何高度的包。

### S10 八个折点拼出正弦
- 画面：右上小图画出宽 8 网络的 8 条折线（各隐藏单元的贡献，各自幅度很大）；左侧主图：数据点作背景，绿线从左往右逐段画出，每经过一个折点（黄点）拐一次弯。
- 屏幕文字：输出 = 8 条折线之和 + b2
- 旁白：训练好的网络就是这样做的。这是一个宽度为八的网络，已经用梯度下降训练过。把它拆开，每个隐藏单元是一条折线，一共八条，就是右上角这些。单看每一条，数值可以大到十二左右，加在一起互相抵消，才得到幅度只有一的曲线。从左往右看，绿线每经过一个折点，就拐一次弯，拼出了一条起伏的曲线。代码验证过：八条折线之和加上 b2，和网络的输出完全一样。所谓神经网络拟合曲线，就是用很多段直线拼出一条曲线。折点放在哪里、每一段有多陡，全都是梯度下降自己找出来的，我们没有告诉它任何关于正弦的事。

### S11 训练：手推梯度
- 画面：从损失往回的链：L → Ŷ → A → Z → W1，每一步写出梯度公式；ReLU′ 用黄色高亮："没激活的单元梯度为 0"；底部：梯度检验差 1.1e-10。
- 屏幕文字：∂L/∂Z = ∂L/∂A ⊙ ReLU′(Z)
- 旁白：网络怎么训练？和第一章一模一样：算损失，算梯度，往反方向走一小步。梯度要从损失往回一层一层推。先得到损失对输出的梯度，乘 W2 的转置传到隐藏层；过 {ReLU|瑞 L U} 时，没被激活的单元梯度直接变成零；再乘上输入，得到 W1 的梯度。这套链式法则就叫反向传播，第四章会系统地讲。我们用数值梯度检查过，手推的结果误差只有十的负十次方。

### S12 看着曲线被拟合出来
- 画面：宽 64 的网络：绿线在第 0、1000、5000、20000 步的样子依次变形，右侧损失数字同步变化。
- 屏幕文字：宽 64，学习率 0.01
- 旁白：用宽度六十四的网络训练两万步。一开始，随机的参数给出一条乱七八糟的折线，损失二点七八。一千步后，大致的起伏已经出来了，损失降到零点一二。五千步，零点零一三。两万步后是零点零零零九，绿线几乎和数据点重合。梯度下降本身没变，变的是模型：它现在能弯了。

### S13 宽度的作用
- 画面：三个并排小坐标系：宽 2、宽 8、宽 64 的最终拟合，下方写参数量和损失；最左边再叠一条灰色的最好直线作对照。
- 屏幕文字：宽 2：0.3155　宽 8：0.0152　宽 64：0.0009
- 旁白：宽度决定了能拼出多少个折。宽度二，只有两个折点，最多三段直线，损失零点三二，比直线好不了多少。宽度八，损失零点零一五，大致形状有了，但拐角还很生硬。宽度六十四，损失零点零零零九，几乎完美。换五个随机种子重跑，中位数也是同样的规律。只要隐藏单元足够多，两层网络可以把一维曲线拟合得任意好，这就是著名的万能近似定理想说的事。当然，拟合得好不等于学得好，这个问题后面的章节还会遇到。

### S14 从极简到生产级
- 画面：左边是手推梯度的 NumPy 几行，右边是 PyTorch 的 nn.Sequential 三行加五行训练循环；底部两行对拍结果。
- 屏幕文字：nn.Sequential(nn.Linear, nn.ReLU, nn.Linear)
- 旁白：同样的网络，用 {PyTorch|pie torch} 写只要三行：一个线性层，一个 {ReLU|瑞 L U}，再一个线性层。梯度不用手推，调用 {backward|back ward} 自动求。把 {NumPy|num pie} 版的初始参数拷进去，同样训练两万步，两边的损失差是十的负十八次方。换成 {PyTorch|pie torch} 默认的初始化，也能训练到零点零零一九。

### S15 小结与下一章
- 画面：三行要点依次出现；然后画面上 NumPy 手推梯度的公式越堆越多、变红；最后出现"下一章：反向传播与自动微分"。
- 屏幕文字：线性层 + 激活函数 = 神经网络
- 旁白：总结一下。线性层叠多少层还是线性；加上激活函数，每个隐藏单元贡献一个折；很多个折加起来，就能拼出任意形状的曲线。但你也看到了，两层网络的梯度，我们已经要推五六行。如果是几十层、上百种运算，手推梯度既累又容易错。下一章，我们让计算机自己求梯度：反向传播与自动微分。你会亲手写一个一百多行的小工具，用它重新训练今天这个网络。我们下一章见。
